# TypeScript

"TypeScript" covers the language that adds types to JavaScript: what the types do, and how the code is compiled and run. Each folder here answers one question.

| Folder | Question it answers | Topics |
|---|---|---|
| `compiling/` | What happens to TypeScript before and while it runs? | compile time and runtime, tsconfig and module resolution |
| `type-system/` | How do TypeScript's types work? | structural typing and narrowing, generics and utility types |

A folder is created when its first topic is added.

## Topic folder layout

```
typescript/<category>/<topic>/
  index.html   page: what it is, diagram with code, problems it solves, problems it introduces
```
