# .NET

".NET" covers the .NET runtime and the frameworks built on it. Each folder here answers one question.

| Folder | Question it answers | Topics |
|---|---|---|
| `runtime/` | How does .NET run C# code? | how .NET works |
| `web/` | How do I build an HTTP API on .NET? | ASP.NET Core |

A folder is created when its first topic is added.

## Topic folder layout

```
dotnet/<category>/<topic>/
  index.html   page: what it is, diagram with code, problems it solves, problems it introduces
```
