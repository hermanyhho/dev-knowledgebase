# React

"React" covers the React library for building user interfaces, and Next.js, the framework built on it. Each folder here answers one question.

| Folder | Question it answers | Topics |
|---|---|---|
| `rendering/` | What does React do when data changes? | how React renders |
| `hooks/` | How do components keep state and work with things outside React? | state and effects |
| `state/` | Where should each piece of state live? | where state lives |
| `nextjs/` | How does Next.js render React on the server and in the browser? | rendering and server components, caching, server actions and proxy |

A folder is created when its first topic is added.

## Topic folder layout

```
react/<category>/<topic>/
  index.html   page: what it is, diagram with code, problems it solves, problems it introduces
```
